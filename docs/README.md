# linux-wallpaperengine Documentation

Start with the [project checklist](Organized%20all.md) for completed work,
open tasks, and pending verification across all project docs. The
[wiki index](wiki/index.md) links the detailed technical references. The
[full corpus report](Full%20Corpus%20Validation.md) lists every installed
wallpaper checked in the latest complete sweep.

Directory layout:

- `wiki/status/` — current status, known issues, backlog, and refactors
- `wiki/rendering/` — renderer architecture and reverse-engineered formats
- `wiki/reference/` — native reference findings, texture format, regressions
- `wiki/workflow/` — repeatable debugging and verification practices
- `wiki/investigations/` — unresolved evidence-heavy investigations
- `wiki/references/` — external convention/source references

`docs/wiki/` is the Obsidian vault. Historical implementation plans and tiny
schema fragments are intentionally folded into maintained pages instead of
kept as competing sources of truth.
